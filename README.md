Sterile Processing Resources

A web-based resource website designed to provide information and educational materials related to sterile processing and healthcare instrument sterilization.

About the Project

Sterile Processing Resources is a front-end web development project focused on making information about sterile processing accessible through a clean, organized, and user-friendly website.

The project demonstrates practical web development skills using HTML, CSS, and JavaScript.

Technologies Used

* HTML5 – Website structure and semantic markup
* CSS3 – Styling, layout, and responsive design
* JavaScript – Client-side functionality and interactivity

Project Goals

* Provide an organized resource for sterile processing information.
* Create an accessible and easy-to-navigate website.
* Support usability across desktop and mobile devices.
* Apply modern front-end development practices.

Skills Demonstrated

* Front-end web development
* Website structure and organization
* CSS styling and layout
* JavaScript programming
* User interface design
* Responsive web design
* Git and GitHub version control

Getting Started

1. Clone the repository:
    git clone https://github.com/ailson320-prog/sterileprocessingresources.git
2. Open the project folder.
3. Open index.html in your browser, assuming it is the project’s main HTML file.
